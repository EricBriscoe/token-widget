## Cause

The September screenshot shows day 1 to the right of the first bar. The
query correctly puts September 1 at index 0. Swift Charts automatically
anchors the axis labels away from the bar centres on the continuous x scale.
The shared chart affects both the dashboard and the widget.

## Fix

Set `AxisValueLabel(centered: false, anchor: .top)` on the bucket axis.
Keep the data indices, date aggregation, and x domain unchanged.

## Verification

`ChartAxisTests.testFirstDayLabelIsCenteredUnderFirstBar` renders the real
chart and compares the first label's ink centre with the first bar's centre.
Before the fix, the difference was 20 pixels at 3x scale. After the fix,
the label and bar align within one point. The test also checks that the
month has 30 buckets and September 1's usage and label occupy index 0.

Run `swift test --package-path Core` (142 tests passed).
